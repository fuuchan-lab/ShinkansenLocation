公共交通オープンデータセンター（ODPT）の開発者サイトに登録し、Web アプリ「のりものレーダー」で JAL・ANA の発着情報を使うためのアクセストークンを取ってください。ブラウザは、すでに私の Google アカウントでログインしている状態です。

## 目的
- アプリの空港の画面に、JAL・ANA の便の定刻・遅延・欠航を出すために、ODPT の API（https://api.odpt.org/api/v4/ ）のアクセストークン（コンシューマーキー）が必要です。
- アプリの中継サーバー（Cloudflare Workers）がこのトークンを使ってデータを取り、空港ごとに5分ためてから利用者に表示します。利用者のブラウザにはトークンを渡しません。

## 手順
1. https://developer.odpt.org/ を開き、ユーザー登録（無料）をする。
   - メールアドレスは、私の Google アカウントのアドレスを使う。
   - 利用目的などを聞かれたら、次のように書く。
     - アプリ名：のりものレーダー（Norimono Radar）
     - URL：https://norimono-radar.doitmyself.net/
     - 内容：日本の新幹線・飛行機・旅客船の位置を地図に表示する、個人が運営する無料の Web アプリ。空港の発着一覧に、JAL・ANA のフライト情報（出発・到着）を表示するために使う。広告なし。
   - パスワードを決める欄が出たら、自分で決めずに止まり、私に入力を頼む。
   - 氏名・住所・電話番号など、上に書いていない個人の情報を求められたら、推測で埋めずに止まって私に聞く。
   - 確認のメールが届いたら、メールのリンクを開いて登録を完了する。
2. 審査や承認待ちの表示が出たら、そこで止めて、表示された内容（審査の有無、目安の日数）を報告する。
3. 登録が終わったら、マイページなどでアクセストークン（「アクセストークン」「コンシューマーキー」「acl:consumerKey」などと書かれたもの）を確認する。
4. 利用規約（https://developer.odpt.org/terms ）と「公共交通オープンデータ基本ライセンス」を開き、次の点を読んで報告する。
   - アプリの画面に必ず書く必要がある文（出典・注意書き）。全文をそのまま写す。
   - データを中継サーバーで一時的にためて（5分）、多くの利用者に表示してよいか。
   - 個人の無料アプリでの利用に、追加の申請や条件があるか。
   - 「チャレンジ限定ライセンス」のデータ（東京国際空港ターミナル）は使わない前提でよいか。
5. カタログ（https://ckan.odpt.org/dataset/?tags=%E8%88%AA%E7%A9%BA-airline ）で、日本航空・全日空の「リアルタイム出発情報」「リアルタイム到着情報」が「公共交通オープンデータ基本ライセンス」であることを確かめる。

## 守ること
- アクセストークンを、ほかのサイトやフォームに入力しない。チャットへの報告以外に書き写さない。
- 有料のプランや、追加の申し込みが必要なものには進まない。
- ほかの既存のアカウントの設定を変えない。
- 迷ったら推測で進めず、止まって私に聞く。

## 報告してほしいこと
- 登録が完了したか（審査待ちなら、その表示と目安）
- アクセストークン（私に直接伝える。私がアプリの作業をしている Claude に渡し、中継サーバーの secret に登録してもらいます）
- 手順4の4点（必須の表示文は全文）
- 手順5の確認結果
